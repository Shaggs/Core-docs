Automatic nightly backups and restoring

Set BACKUP_PASSPHRASE in .env, then add to cron:

30 2 * * *  cd /path/to/Core-docs && .venv/bin/python backup.py create

To restore (stop the web app first; current data is moved aside, not deleted):

python backup.py restore {{ backups[0].name if backups else 'coresightvault-backup-YYYYMMDD-HHMMSS.cvbak' }}

Also back up your .env file separately. It holds the key that decrypts stored passwords and is intentionally not inside the backup. Copy backups off this server too (another machine or cloud storage).
